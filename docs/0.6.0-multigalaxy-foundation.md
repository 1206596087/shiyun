# 多银河基础版验证记录

本增量按用户优先级提前交付 prompt3 的多银河第一条完整链路，不代表 0.6.0 或 prompt3 全部完成。

## 已实现

- SQLite 版本 3 新增 Galaxy、GalaxyLayout、GalaxyMembership；同一知识对象可属于多个星系，原始实体不复制。
- 宇宙总览使用独立低细节 Three.js 场景；进入单个星系后继续使用原有银河场景与知识交互。
- 创建、改名、说明、颜色、拖动位置、进入、返回、删除星系；删除只移除集合并把孤儿安全送回默认星系。
- 跨星系光带只由真实 `knowledge_links` 聚合生成；纯函数测试覆盖多归属与去重。
- 低性能模式减少总览点数；几何与材质在卸载时释放。
- 镜头飞入带定时兜底，低帧或后台窗口不会让“进入星系”永久卡住。

## 实机与自动验证

- 独立临时数据目录创建 5 个星系，桌面总览显示不同位置、颜色和旋臂参数；列表 CRUD 与数据库迁移版本 3 正常。
- 真实 `2026级研究生作业.pdf` 在带失效旧文件夹 ID 的条件下导入成功并落到未分类。
- 打开该 PDF 后文本层 87 个 span；真实选区浮动工具条显示标记、写笔记、复制、翻译、搜索，保存标记后页面出现 1 个可点击高亮且“我的划线”计数变为 1。
- 类型检查、Lint、107 项测试和生产构建通过（最终提交前复跑）。

## 已知限制

- 光带详情暂只显示关系数量，尚未列出具体节点或区分人工确认与系统推荐。
- 初始正式库只有默认星系；其他星系由用户创建，不用虚构业务分类填充用户数据库。
- PDF 仍是单页模式；连续滚动实验模式是下一项。
- 本轮在 macOS Electron 独立库验证，未声称新的 Windows 安装包已经复测。
