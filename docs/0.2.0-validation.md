# 0.2.0 开发与验证记录

本轮在 macOS 本机继续开发 Windows 项目，未替换银河、阅读器或数据库架构。源代码来自 GitHub 压缩包；网络两次阻止 git clone，本地独立基线为 e92e14c，尚未同步远端历史或推送。

## 实际实现

- 文件协议按最多 64 KiB 的缓冲区读取，支持完整响应、HEAD、闭区间、开放区间、后缀区间、416 与取消读取。PDF.js 禁止自动下载剩余内容，保留默认单页阅读。
- PDF/EPUB 组件懒加载，加载时有提示。首屏构建产物从 5,622.48 kB 降到约 4,111 kB（未压缩，约减少 27%），两个阅读器独立成块。
- 设置与回收站显示真实路径、数据库版本、最近备份，打开目录、手动数据库备份、导出完整知识库、恢复书籍/笔记。研究栏在打开设置时隐藏，避免原生网页遮挡面板。
- 笔记软删除保留 highlight_notes；删除前等待正在进行的保存并提交待保存内容。恢复后正文与原始关联仍在。旧版本已经硬删的关联无法凭空恢复。
- 002 迁移新增 trigram 全文索引及触发器，笔记创建/编辑/删除/恢复自动更新索引。我的笔记支持正文/标题检索及文本高亮；一到两个字符使用有限结果的子串查询（可能扫描，未宣称高性能术语引擎）。
- .shiyunbundle 导出使用 VACUUM INTO 一致性快照、相对路径、文件大小和 SHA256。还原脚本只允许新目录，验证头部、路径、长度、哈希、SQLite 完整性，不覆盖现有书库。自动数据库备份也改为 VACUUM INTO。

## 验证与范围

- 基线 82 测试，修改后 97 测试；typecheck/lint/test/build 均通过（最终状态以提交记录为准）。
- macOS Electron 真实运行：preload/IPC、中文“极大似然”检索、笔记软删/回收站/恢复、设置页真实信息通过。脚本 scripts/e2e/desktop-smoke.mjs。
- 仓储测试覆盖三条划线关联及最新正文恢复、索引更新与查询语法安全；导出/还原测试覆盖 WAL 最新正文、原件一致、损坏包拒绝、已有目录拒绝。
- 64 MiB 合成双页 PDF 在实际桌面阅读器打开并显示文字；它是大体积协议验证文件，不代表复杂扫描教材性能。
- 独立进程读取 64 MiB 文件的前 64 KiB：旧实现 RSS 增量约 65 MiB，新实现约 10.3 MiB（含 Request 初始化）；单次用时约 9.66 / 10.16 ms，未证实首屏更快，不能把此结果称为完整性能验收。需复杂教材、重复冷启动和峰值采样进一步验证。
- 当前没有 Windows 运行环境，未声称 Windows 安装器/异机还原已实测。macOS 新目录还原已通过。

## prompt2 审查

双空间、SQLite 书库、真实阅读、划线多对多关联、星图投影、原生网页视图与安装配置都有代码实现，基础不是静态演示。但原进度表把 M3/M6/M7 全部标完成，超过了完整需求的实际覆盖范围：连续阅读、原文搜索、网页多标签、Markdown 导入导出及完整迁移流程仍有缺口。文档早期 M1/M2 描述与后期状态混杂，本轮记录作为当前增量事实，不能把历史截图当作本轮 Windows 验收。

新增依赖：无。参考 Node.js 的 FileHandle/read API、SQLite FTS5/trigram 与 VACUUM INTO 官方文档；未复制外部项目代码。后续大模块仍应逐个进行许可证和体积评估。

## 已知限制和后续

- 本轮为 0.2.0 开发候选，六项严格验收仍缺真实复杂教材的首屏性能对比和 Windows 异机还原。
- 回收站暂不提供永久清除、列表右键、删除撤销；可在设置中恢复。已打开的笔记恢复后需关闭该标签再打开。
- 设置尚无默认缩放/关联灵敏度。无恢复到当前书库或冲突合并界面；0.7.0 接入。
- 导出含数据库、books/attachments/assets；浏览器 localStorage 中的栏宽等 UI 偏好不在导出内。尚不存在的思维导图/分子结构不宣称已支持。
- VACUUM INTO 为同步快照，大库会暂时占用主进程；未来可评估独立连接/后台任务。
- 依赖安装审计报告 9 项漏洞（7 moderate、2 high），未自动进行破坏性升级，需单独评估依赖路径与版本。
- 下一版本按 prompt3 为 0.3.0：连续滚动实验开关、多行高亮、选区适配器、多标签浏览器。

## Windows 接续验证与 0.3.0 实验增量

在远端 `feat/0.2.0` 的 `2459585` 基线上继续。Windows 本机基线 `typecheck / lint / test / build` 通过（107 项测试）；连续阅读窗口算法加入后为 109 项。

PDF 连续阅读已作为默认关闭的实验开关加入。自动化用全新 `SHIYUN_DATA_DIR` 启动 Electron，并导入由 Edge 打印的中文多页 PDF：初始单页模式只有 1 个 canvas；连续模式文档保留全部轻量占位，第一页只挂 2 个页面表面，进入第二页后只挂 3 个 canvas / 3 个文本层。测试脚本与夹具在 `scripts/e2e/pdf-continuous-*`，真实用户书库未被打开或修改。

本次没有数据库迁移或新依赖。连续模式仍需复杂教材、旋转页和混合纸张尺寸压力测试；跨页选区尚未实现。
