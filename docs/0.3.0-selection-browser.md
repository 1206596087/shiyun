# 0.3.0 选区与网页研究增量

本记录只描述本轮已实现并验证的增量，不代表 prompt3 全部完成。

## 已实现

- PDF / EPUB 选中文本后显示浮动工具条：gold、rose、sage 三色标记，写笔记、复制、翻译、搜索与关闭。
- TipTap 笔记正文使用同样的三色标记、复制、翻译、搜索操作；标记作为 `selectionHighlight` Mark 写入笔记 JSON。
- 翻译与搜索通过内部事件在研究栏新建网页标签，不覆盖正在阅读的网页。中英文翻译方向由选文粗略判断，使用 Bing Translator；文字只在用户点击翻译后发送。
- 网页研究支持最多 12 个真实标签，可新建、切换、关闭；各标签保留自己的历史、错误和 50%–200% 缩放。网页弹窗被转换为受控的新标签。
- 研究栏提供紧凑、扩展、沉浸三种布局并记住选择；可拖宽到 900px。新安装默认宽度由 294px 调整为 360px。
- 在网页中选中文字后，可从底部执行翻译、保存本地摘录、复制；摘录含网页标题与来源 URL。
- 左上角标识替换为原创的银河轨道图标，没有引入外部图片素材。
- PDF/EPUB 导入先验证真实文件头，再临时复制并复核大小和 SHA-256，原子改名成功后才写数据库。失败不留下书目或半文件。

## 验证

- 单元及仓储测试共 101 项通过，包含翻译/搜索 URL 边界、伪 PDF 拒绝且无残留、真实导入后数据库重开仍能定位托管源文件。
- macOS Electron 使用独立临时书库实测：导入 PDF 后退出再启动仍可打开；PDF 选区工具条八个动作可见；翻译新建 Bing Translator 标签并带入原选文。
- 真实 Wikipedia 页面同时打开多个标签，完成切换、关闭及单标签 120% 缩放；可提取真实网页选文。
- `typecheck`、`lint`、`test`、生产构建和补丁空白检查全部通过。

## 尚未完成

- prompt3 其余大项仍需逐项开发，尤其 PDF 连续滚动/虚拟化、逐行高亮渲染的进一步打磨，以及完整跨版本验收。
- 网页标签暂不在重启后恢复。第三方网页属于原生视图，应用不会向其中注入浮动工具条；网页动作固定在研究栏底部。
- 本轮在 macOS 完成桌面实测，没有声称新的 Windows 安装包已复测。
